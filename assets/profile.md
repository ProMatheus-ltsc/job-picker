# 考生画像（输入模板）

> 复制本文件填写后，作为筛选与资格审查的输入。**每一项都影响判定结果，宁可留空也不要猜。**
>
> 留空 = 该项**不参与判定**（不会误杀岗位）；填错 = 误判。拿不准就留空。

## 一、硬条件（决定"能不能报"）

| 项 | 值 | 备注 |
|---|---|---|
| 学历 | 本科 | 以毕业证为准；研究生填最高学历 |
| 学位 | 学士 | 部分岗位要求"学士及以上" |
| 专业（主修） | 法学 | **填毕业证上的规范名称** |
| 专业（第二学位/辅修） | 物理学 | ⚠️ 是否认可需**致电招录单位**确认 |
| 专业大类 | 法学类 / 物理学类 | 按教育部《专业目录》 |
| 毕业年份 | — | |
| 应届身份 | 否 | 影响大量岗位 |
| 政治面貌 | 群众 | 党员/团员会解锁受限岗位 |
| 基层工作经历 | 5 年 | 以社保/合同为准；影响"2年以上基层"类岗位 |
| 法律职业资格 | 无 | 部分法检岗硬性要求 |
| 户籍 | 广州 | 国考基本不限；**省考部分岗位限户籍** |
| 年龄 | 1993 年生 | 国考上限 38；省考多卡 35 |

## 二、工作强度与形态（决定"值不值得报"的第一道硬筛）

> ★ 这一组是 2026-11-04 沉淀的核心能力：一天里用**一句话**筛掉 433 岗中的 265 个（61%）。
> 强度是**硬筛**，不是加权——不满足就直接排除，不参与打分。

| 项 | 值 | 说明 |
|---|---|---|
| 接受值班 / 夜间 / 轮班 | 否 | 「否」→ 职位简介/招考职位/其他要求含"值班/24小时/夜间/轮班/值守"一律排除 |
| 接受应急 / 三防 / 消防 / 救援 | 否 | 「否」→ 含"应急/三防/消防/救援/防汛/森林防火"一律排除 |
| 接受执法勤务 / 一线 / 处突 | 否 | 「否」→ 含"执法/执勤/巡查/一线/处突"一律排除；行政执法卷另有备考结构影响 |
| 接受信访 / 接访 / 维稳 | 否 | 记为轻量提示（light），交人工判断 |
| 接受外派 / 常驻 / 出差 | — | 记为轻量提示（light） |

> **实现口径**：以上四项任一为「否」，对应类别升级为 `heavy` 并直接排除；
> 「—」表示只提示不排除。扫描范围**必须包含职位简介**（历史教训：5 个综合岗的信号只写在简介里）。

## 三、软偏好（决定"选哪个"）

| 项 | 值 | 说明 |
|---|---|---|
| 目标城市 | — | 支持模糊匹配（填"广州"命中"广东省广州市南沙区"）；同时触发**范围外提示** |
| 排除哪些区 | — | 如「越秀」→ 该区岗位直接排除（来源可信度自定，属个人判断） |
| 可接受最低年薪 | — | 单位：万元（年全包口径 = 到手 + 双边公积金）；低于此值的岗位排除 |
| 接受 5 年最低服务期 | 否 | 「否」→ 来源表=乡镇机关（及其他标注长期服务期）的岗位排除 |
| 是否接受县级 / 乡镇 | — | 与上一条独立：乡镇岗不一定都带 5 年服务期 |
| 住房情况 | 西安有房（月供 4,800，20 年） | 影响"实际可支配收入"计算 |
| 现居地 | 广东 | 影响通勤 / 面试成本 |
| 其他约束 | — | 健康（如膝盖）、家庭等 |

## 四、笔试基线（决定"概率"是否可算）

> 概率模型的输入全是 **C 级**（自报/估计），所以**不给就别算**——
> 输出「—」比输出一个假数字好。缺这组值时，报告只给薪酬与竞争度，不给进面概率。

| 项 | 值 | 说明 |
|---|---|---|
| 笔试折算基线 μ | 67 | 最近一次整卷模考的折算分；没有模考就别填 |
| 整卷波动 σ | 3.5 | 建议用最近 3 次整卷的标准差；模考 0 次时填 3.5 属**主观给定** |
| 模考次数 | 0 次 | 次数越少，μ/σ 越不可信（报告会据此调低置信度） |

## 五、输出时的注意

1. **专业填写口径**：国考里「法学」与「法学类」是两个不同口径，**两个都填**能多捞一批按大类招的岗位。
2. **双学位**：国考备注常写"专业条件为报考者最高学历对应专业" → **报名前务必致电确认**。
3. **硬条件留空** = 该项不参与判定（不误杀）；填错 = 误判。宁可留空。
4. **排除区要写明理由来源**：如「越秀——公务员朋友反馈欠薪」，因为这是 C 级个人判断，
   报告会把它标成 C 级而非事实。
