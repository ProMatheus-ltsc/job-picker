## 一、数据获取类

### 1. 国家公务员局下载页是 JS 渲染
- **现象**：`curl` 下载页只得到 2 KB 的空壳 `<ul id="download_ul">`
- **原因**：列表由 `gkdownloads.js` 异步填充
- **修法**：走接口 `http://dl.scs.gov.cn/api/res/{webRootId}/1110` → `resList`

### 2. webRootId 跨年度会变
- **现象**：2027 的 id 是 `8a81f6eca0221f1401a0242759fc0000`，硬编码后换年份就失效
- **修法**：从 `core-constant.js` 动态读 `neu.hb01Id`

### 3. 资源列表在公告当天下午才出现
- **现象**：10/13 上午 11:10 查 `resList` 为空；14:04 再查出现「招考简章.zip」
- **修法**：不要因为"列表为空"就认为没发布，下午再查

### 4. 税务系统官网普遍有 WAF
- **实测（2026-10-13 首测）**：总局 `www.chinatax.gov.cn` → 403；宁波 → 412；陕西 → 000
- **实测（2026-10-14 复测，同一沙箱）**：总局 `www.chinatax.gov.cn` → **200 可达**；
  广东 → 200；浙江 → 200；**陕西 → 412**（首页与文章页都拦，但见 #26）；宁波 → 412
- **结论**：WAF 状态**会随时间变化**，不要照抄历史结论；每次都重新测一遍
- **修法**：脚本报错时提示"在本机运行"；**不得**因此改用第三方镜像

### 5. 附件相对路径的基准是页面所在目录
- **现象**：页面 `.../2026-02/02/content_abc.shtml` 里 `href="abc/files/x.xls"`
- **错误拼法**：`.../content_abc.shtml/files/x.xls` → 404
- **正确**：`.../2026-02/02/abc/files/x.xls`（用 `urljoin(page_url, href)` 自动处理）

## 二、解析类

### 6. 面试名单表头含换行
- **现象**：列名实为 `进入面试\n最低分数`，直接按 `进入面试最低分数` 取会 KeyError
- **修法**：列名归一化（去 `\s` `（）` `：`）

### 7. 同一岗位多行，只有首行带分数
- **现象**：一个岗位 3 个进面考生占 3 行，只有第一行有分数
- **修法**：对「职位名称及代码」列**前向填充**（`ffill`）

### 8. 主名单与递补名单同代码重复
- **现象**：递补公告会再发一份名单，同职位代码重复出现且分数不同
- **修法**：同代码去重，**保留分数更高者**（主名单分数 ≥ 递补）

### 9. 职位代码需从"单位+职位"串里提取
- **现象**：多数税务局把代码并在名称里：`国家税务总局XX税务局一级行政执法员（二）（300110101002）`
- **修法**：正则 `(\d{12})` 提取，并剥离尾部括号

## 三、资格审查类（job-picker 引擎）

### 10. 国考职位代码**跨部门重复**
- **现象**：省级以下 18193 行，唯一「职位代码」仅 6339 个 → 按代码去重**丢掉 2/3 岗位**
- **实例**：`300110004001` 同时属于北京市通信管理局·业务处室 和 内蒙古自治区通信管理局·政策法规处
- **修法**：唯一键用「职位代码 + 用人司局」

### 11. 限应届的国考写法
- **现象**：规则只匹配「应届毕业生」连写，漏掉「**2027届**高校毕业生」
- **后果**：9008 个限应届岗位被误判为"符合"
- **修法**：覆盖 `XX届高校毕业生 / 应届高校毕业生 / 仅限XX届`

### 12. 专业匹配：太松与太紧都错
- **太松**：「大气物理学与大气环境」（属大气科学类）被 `includes("物理学")` 命中 → 5 个气象局岗位误入
- **太紧**：「大学本科：法学类（030101K）」带前缀未剥离 → 漏判央行阳江岗
- **修法**：按分隔符 `[,，、;；/／]` **切段** → 剥离括号内代码 → 剥离 `大学本科：` 类前缀 → **精确比对**段

### 13. 岗位代码与会话内的其他字段同名
- **现象**：zsh 环境下变量名 `path` 与内置 `$path`（绑定 PATH）冲突，把环境搞坏
- **修法**：脚本内不要用 `path` 作变量名

## 四、省考职位表（与国考差异大）

### 14. 表头不在第 1 行
- **现象**：广东 6 个 sheet 的表头分别在**第 2 行或第 3 行**，且各不相同
- **修法**：自动探测表头行（在前若干行里找"同时含职位与人数列"的行）

### 15. 专业拆成多列
- **现象**：广东拆为「研究生专业名称及代码」「本科专业名称及代码」「大专专业名称及代码」
- **修法**：`Mapping` 值类型扩展为**数组**，支持一字段合并多列

### 16. 广东专业列含括号代码
- **现象**：`哲学(A01),经济学(A02),法学(A0301)`
- **修法**：先剥离 `(...)` 再切段比对

### 17. 浙江「现有身份要求」= 「2025年应届毕业生」
- **现象**：`parseGrassrootsYears` 用 `/(\d+)/` 抓数字 → 抓到 **2025** → 判成"要求 2025 年基层经历" → 5 < 2025 → **1884 个岗位被误杀**
- **修法**：含「应届」直接返回 0；数字必须紧跟「年」单位；加负向边界（顺带修掉 `1988年` 被截成 `88年`）

### 18. 定向招录被静默放过
- **现象**：「优秀村干部 / 退役军人 / 服务基层项目人员」无法解析年限 → 判 pass → 普通考生报不了却显示"符合"
- **修法**：无法识别的身份文本降级为 `warn`

### 19. 体测门槛可能不在表格里
- **现象**：广东公安的体能测评要求写在**公告正文**，表格无此列 → 文本扫描抓不到
- **修法**：浙江有独立「是否体能测试」列 → 新增字段；广东侧改为识别单位名含公安/监狱/戒毒/边检

## 五、数据来源类（★ 最重要）

### 20. 进面分只在面试名单里，职位表没有
- **现象**：一度用"两个极端值外推四档区间"（如城区 130–140）
- **后果**：西安新城区实际 **116.9**，外推值 130–140 → **偏差 13–23 分**
- **修法**：**一律从面试名单取**，取不到就写"无法获取"

### 21. 第三方镜像虽然内容相同，也不能当作来源
- **现象**：官网被 WAF 拦时，机构 CDN（如 `u3.huatu.com`）能拿到官方附件原文
- **问题**：无法验证未被修改，且来源不可追溯
- **修法**：`_guard.py` 域名白名单**硬拦截**；官网不可达时如实报告，请用户在**本机**重试

### 22. 历史报录比没有一手来源
- **现象**：官方只在**报名期**实时公布报名人数，考后关闭
- **修法**：不提供历史报录比；用**进面分**作竞争度代理（一手、可查）

### 23. ★ 12 位职位代码**跨省不唯一**（与 #10 是两回事）
- **现象**：税务系统各省局**独立编号**。实测 `300110106001` 同时出现在**广东 / 浙江 / 陕西**的名单里，
  且单位完全不同（珠海万山海洋开发试验区税务局 / 温州市税务局第二稽查局 / 西安市灞桥区税务局）
- **数量**：本次三省 1182 个岗位中有 **134 个代码跨省重号**（约 11%）
- **后果**：按「职位代码」单键去重，会把别省的岗位**静默吃掉**——总数变少但看不出任何异常
  （实测：1040 vs 正确 1182，少了 142 个）
- **修法**：唯一键必须用 **(省份, 职位代码)**；`lookup` 按代码聚合、把命中的所有省份都列出来并给警告
- **同理**：**跨年度也不复用**——陕西 2021 年 `300110001001` 是「西安市新城区税务局」，
  2026 年是「陕西省税务局稽查局」。所以拿旧代码直接查今年岗位是无效的

### 24. 前向填充必须**先于**按代码筛行，否则「进面人数」恒为 1
- **现象**：解析出的每个岗位 `进面人数` 都是 1，但原始表明明有 3~9 行
- **原因**：代码先执行了「只保留含 12 位职位代码的行」——而**续行的代码列是空的**，
  整行被删掉，后面的 `ffill` 就没有东西可填了
- **修法**：顺序改成 ① `ffill` ② 提取代码 ③ 判「考生行」（姓名或准考证号非空）④ 分组计数
- **验证**：`进面人数` 合计应等于「原始表总行数 − 表头行数」（本次 4020 / 2117 / 2150 完全对上）

### 25. CMS 下载链接里没有文件名，且 `ATTACH_RE` 不能拿裸 URL 去匹配
- **现象 A**：浙江/陕西的附件链接形如
  `/module/download/downfile.jsp?classid=0&filename=<uuid>.xls` —— **URL 里没有可读文件名**
- **现象 B**：广东的链接路径就是 `<uuid>.xls`，真名只写在 `<a>` 的 **文字或 `title` 属性**里
- **后果**：只按 URL basename 命名，会让同一页的多个附件重名互相覆盖
  （浙江 6 个附件全存成 `downfile.jsp.xls`）；广东则全是 UUID 名，`来源文件` 字段无法追溯
- **坑中坑**：`ATTACH_RE = 'href="([^"]+\.(?:xls|…))"'` 匹配的是**整个 `href="…"` 片段**，
  拿已经拆出来的**裸 URL** 去 `ATTACH_RE.search()` **恒为 None** → 所有附件都掉进无文件名的兜底分支
- **修法**：① 正则同时捕获 `<a>` 标签与内部文字（文字为空再取 `title`）；
  ② 附件判定改用独立函数（看路径后缀，或 `filename/showname` 查询参数）；
  ③ 重名自动加 `(n)` 后缀，不静默覆盖

### 26. 陕西站 412 是「瑞数」动态 JS 防护，但**附件下载接口不受保护**
- **现象**：`https://shaanxi.chinatax.gov.cn/` 与 `/art/…html` 全返回 **412**，
  响应体是混淆 JS + `$_ts` 变量 + 设置 cookie 后重载，属瑞数动态防护，requests 无法直接过
- **但是**：`/module/download/downfile.jsp?classid=0&filename=<uuid>.xls` → **200，348 KB 正常**
  （WAF 只护 HTML 页面，不护文件下载 servlet）
- **修法**：**分工取数** —— 用浏览器或 **WebFetch 打开公告页拿附件 UUID**（WebFetch 能过 WAF），
  再用 `requests` 直连 `downfile.jsp` 下载；`fetch` 已支持传附件直链
- **同类**：`www.scs.gov.cn` 也是 JS 挑战页（`__tst_status` cookie），并非真不可达

### 27. 县/县级市税务局的名称里没有省级关键词 → 省份识别失败
- **现象**：`国家税务总局建德市税务局`、`国家税务总局博罗县税务局` —— 既没有「浙江/广东」，
  `国家税务总局([\u4e00-\u9fa5]{2,6}?)(?:省|市|自治区)` 也只能抓到「建德」，落不进映射表
- **后果**：`省份` 字段出现 `建德 / 乐清 / 龙港 / 玉环 / 兰溪 / 龙泉 / 江山 / 永康` 等县级市名
- **修法**：① 县级市不认识的**不要提前 return**，继续走关键词兜底；
  ② 兜底仍失败 → 用**该文件的多数省份**修正（一份面试名单只覆盖一个省，这个假设很稳）
- **附带**：把常见的县级市补进 `CITY_TO_PROVINCE`（浙江：建德/乐清/龙港/玉环/兰溪/龙泉/江山/永康/安吉/嘉善…）

### 28. 旧年度的考录专题站已下线，历史进面分只能回省局取
- **现象**：`http://bm.scs.gov.cn/kl2026`、`/kl2025` → **404**（nginx）
  现存的只有当年度 `kl2027`，而其「相关下载」只有招考简章 + 报名表格
- **含义**：`sources.py` 里那句「国家公务员局一次拿到全量面试名单」**只对当年有效**，
  一旦跨年度，那年的专题页会消失
- **修法**：取**历史**进面分一律走**各招录机关（省局）官网**的面试公告栏目；
  同时别指望"一个文件覆盖全国"
- **补充实测（2026-10-14）**：国家局下载接口 `/api/res/{root}/{cid}` 的分类 id 换成
  `1100~1130` 任意值都返回**同一份当年资源列表**（参数形同虚设），
  即老年度文件在下载服务器上**也拿不到**。

### 29. ★ 瑞数 WAF 只护 HTML 页面，`/module/*` 接口一律放行
- **这条是本项目突破 WAF 的通用打法**，两个可用通道：
  1. **文件下载**：`/module/download/downfile.jsp?classid=0&filename=<uuid>` → 200 正常返回文件
  2. **列表检索**：`/module/xxgk/search.jsp` → 200，能拿到栏目全量文章列表
- 被拦的只有：`/`、`/index.html`、`/col/…`、`/art/…`、`/robots.txt`、`/sitemap.txt`、`/jsearchfront/…` → 全部 412
- **实操**：不要去执行 JS 挑战、不要装无头浏览器。**页面用 WebFetch 读，数据用 `/module/*` 直连**。
  （本次就是靠这个把"陕西站完全不可达"变成"三省全部取到"。）

### 30. 陕西站（苏迪 CMS）信息公开列表的正确调法 ★ 已固化为命令
- **现象**：`POST /module/xxgk/search.jsp` 若参数不全，返回 `请传入正确参数！`（57 字节）
- **可用最小参数集**（缺一不可，**多了也不行**）：
  ```
  POST /module/xxgk/search.jsp
  infotypeId=A07              # 人事管理
  jdid=1
  area=11610000160006543      # 该站的信息公开区域码
  columnid=32162              # 公务员招录栏目
  divid=list
  ```
  另外必须带 `X-Requested-With: XMLHttpRequest` 与 `Referer: …/col/col32162/index.html`
- **坑 1**：多加的参数（`page` / `currentpage` / `pagenum` / `startrecord`…）会让它退回「请传入正确参数」，
  或**被直接忽略**——实测 8 种分页参数全部无效，接口**固定返回最新 20 条**（一般覆盖近两年，够定位年度公告）
- **坑 2**：浙江站是**同一套 CMS**，只是参数不同
  （`infotypeId=Z2402 & jdid=15 & area=11330000002484088Y & columnid=24800`）；
  **广东站不是**这套 CMS，没有该接口
- **✅ 已固化为命令**，不用再手工拼参数：
  ```bash
  python3 scripts/interview_scores.py discover --site list
  python3 scripts/interview_scores.py discover --site 陕西 --year 2025 --kw 面试
  ```
  预设表在 `SITES`（`scripts/interview_scores.py`）；新增省份只需补 `columnid/infotypeId/jdid/area` 四项
- **返回**：一个 HTML 表格，含 20 条文章（标题 + 责任处室 + 日期 + 链接）

### 31. 该 CMS 的锚点用**单引号**，双引号正则会漏掉全部链接
- **现象**：`href='https://…/art/2025/2/5/art_32162_637838.html?xxgkhide=1'`
  → 只写 `href="…"` 的正则命中 **0 条**，但用「找 `art_xxxxx_xxxxxx.html` 子串」的宽正则能命中 20 条
- **后果**：会误判为"列表页没有链接 / 接口没返回数据"
- **修法**：解析政府站 HTML 时，`href` 的引号**两种都要兼容**（`href=["\']([^"\']+)["\']`）

### 32. `_unique_path` 只查内存不查磁盘 → 分批 fetch 会静默覆盖附件
- **现象**：先抓浙江、再抓广东的 2025 递补公告，两个附件都叫 `递补面试人员名单.xls`
  → 第二次把第一次的文件**覆盖**了，且文件名相同、大小接近，肉眼几乎发现不了
- **原因**：重名集合 `used` 是 `fetch()` 内的局部变量，每次进程调用都重置，**不查磁盘**
- **修法**：去重判断同时看 `used` 和 `os.path.exists(outdir/name)`
- **更稳的做法**：跨省抓取时，别依赖自动命名，**抓完立刻重命名为 `省份_年份_名单类型.xls`**，
  并在解析前用「单位名里出现的省份关键词」反查文件归属（本次就这样救回了被覆盖的浙江递补）

### 33. WebFetch 对同一站点的个别页面会偶发「No readable content found」
- **现象**：同一站点、同样结构的两页，一个能读、一个连续 3 次报
  `No readable content found on the page`
- **修法**：**加一个无害的查询参数破缓存**再试，例如
  `…art_32162_637838.html?xxgkhide=1&v=2` —— 加上后立刻读到了完整正文与附件直链
- **不要**因此就判定"页面为空"或"站点不可达"

### 34. 不要为了过 WAF 去装无头浏览器 —— 本次是死路，且有环境坑
- **过程**：为攻破陕西站，装了 `agent-browser`（`npm i -g agent-browser`）想用真浏览器过瑞数挑战
- **结果**：**完全没用上**。真正解决问题的是 #29 的 `/module/*` 接口
- **若将来确实要用，两个坑先记下**：
  1. `npm i -g agent-browser` 生成的 shim 在 **Git Bash 下路径拼错**：
     `Cannot find module 'c:\c\Users\…'`（`/c/…` 被当成相对路径又加了盘符）→
     绕过办法：`node "$(npm root -g)/agent-browser/bin/agent-browser.js" <cmd>`
  2. 本机**没有 Chrome**，会自动去下载（~数百 MB）→ 改用系统自带的
     Edge：`--executable-path "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"`
     （注意：`--executable-path` 在守护进程已启动时会被忽略，必须先 `close`）
- **结论**：**先试 `/module/*` 接口通不通**；通了就完全不需要浏览器



### 35. 广东省考「06法律类」被判专业不符 —— 两套学科编码没归一
- **现象**：广东省考 8211 行职位表里 111 行专业写「06法律类」，`pick.ts` 全部判 fail，
  候选池因此漏掉一整批「按门类招」的岗位（这类恰恰专业限制最宽、竞争最小）
- **原因**：`majorHit` 只剥 4 位学科码（`/^\d{4}[A-Za-z]?/`，国考写法 `0702物理学`）。
  广东用的是**研究生目录**编码：`06法律类`（06=法学门类）、`07理学类`，
  是 **2 位**数字，剥不掉 → 段名残留「06法律类」≠「法学」
- **修法**：`stripMajorCode` 同时剥 `^\d{1,4}[A-Za-z]?\d{0,3}` 与 `^[A-Za-z]\d{2,6}[A-Za-z]?`；
  并加 `MAJOR_FAMILIES` 把「法律类/法学/法学类」「理学/物理学/物理学类」归为同一门类族
- **边界**：「法医学类」不能被「法学」的族匹配命中（已验证 fail），所以族匹配用**全等**而非 includes

### 36. `是否限应届毕业生报考` 列不是「是/否」，是「应届毕业生 / 2027届高校毕业生」
- **现象**：广州+深圳 91 个候选里 **22 个限应届**，全被判成可报（用户是非应届）
- **原因**：`eligibility` 只判 `/^是$/`，广东该列实际取值是
  「应届毕业生」「2027届高校毕业生」「否」三种 → `/^是$/` 永不命中
- **后果**：上一轮据此推荐的两个「A 档」岗位（荔湾区科技工信局、荔湾区民政局婚姻登记处）
  都写着「2027届高校毕业生」，实际不可报 —— **推荐错了**
- **修法**：`fc && !/^否$/.test(fc) && (/是|应届|\d{4}届/.test(fc) || isFreshOnly(fc))` → fail

### 37. 性别限制完全没判定，8 个「限女性」岗被推给男性考生
- **现象**：广东「其他要求」列直接写「男性」/「女性」，`judgeJob` 里没有任何一步看它
- **原因**：`report.ts` 里 `hardGates(job).filter(g => g !== '性别限制')` —— 主动把性别提示丢掉了，
  且 eligibility 也没有对应判定 → 性别限制两头都不管
- **修法**：`Profile` 增 `gender`，eligibility 加 ⑤b 步判 fail；
  `hardGates` 保留 `性别限制`（供 UI 提示），report 侧继续过滤（已由判定兜住）
- **注意**：「适合男性」不是硬门槛，判 fail 只认「限男性/仅限男性/男性」这类断言写法

### 38. 职位类型决定申论考哪张卷，engine 完全没消费 `institution`
- **现象**：广东 `职位类型` 列取值 = 综合管理类 / 行政执法类 / 公安机关执法勤务，
  它决定申论考《申论》还是《行政执法专业和申论》（**多一门没准备过的科目**），
  但旧 `hardGates` 只扫备注里的「加试/专业测试」字样，广东根本不这么写
- **修法**：`hardGates` 增加 `if (/行政执法类/.test(job.institution)) g.push('加考行政执法')`
- **效果**：报告排序把综合管理类浮到前面（有 gate 的排后），符合「用同一套备考打两场」的策略

### 39. 薪酬档位表漏了广东 11 个考区 → 3630 个岗位被标成「中西部普通地级市」
- **现象**：`salaryTable` 里出现一个 3510 个岗位的「普通地级市（估算）」桶，basis 写「中西部」
- **原因**：广东考区共 21 个，`VERIFIED` 只收了 10 个（广深佛莞珠中惠江汕头湛江），
  肇庆/茂名/梅州/清远/河源/韶关/揭阳/阳江/汕尾/云浮/潮州 11 个落到 `DEFAULT_TIER` 9-13 万
- **后果**：粤东西北被系统性低估 3~5 万，选岗时会误判性价比
- **修法**：`TIERS` 最前面加广东非珠三角规则 → 「粤东西北」13-16 万，basis 注明「无一手数据」
- **仍未解决**：`scripts/budget_salary.py`（部门决算 → 人均工资福利支出）**至今没建**，
  所以 salary.ts 全表的 basis 都是「调研汇总」，**不符合 SKILL.md §一 的数据铁律**，
  输出时必须标注「非官方口径」

### 40. 决算表的「科目编码」长得像金额，把 30205 当成 30,205 万元
- **现象**：广东省税务局 2024 年度单位决算（PDF p16）算出明细 12 项合计
  1,439,986.38 万元，比工资福利支出 1,381,221.16 万元 **多出 4.3%**
- **原因**：基本支出决算明细表是**三栏并排**（人员经费 / 公用经费 / 资本性支出，
  每栏「科目代码 + 科目名称 + 决算数」）。`30107 绩效工资` 决算数为空，
  往右找第一个数字就落到**邻栏的科目编码 30205** 上，`float('30205')` = 30205.0 →
  「绩效工资」凭空多出 30,205 万元；「医疗费」同样吃到 30213
- **修法**：取数改成**只认紧邻单元格**（右边紧邻是文字即判该行无值），
  且纯整数 3~8 位、右侧紧邻仍是文字 → 判为科目编码不取。修后 12 项相加与总额**分毫不差**
- **同类坑**：跨页找明细会把「财政拨款表 / 上年数 / 说明段」的同名科目混进来，
  口径不同不能相加 → 明细**只在总额所在那张表里取**，取自别处必须告警

### 41. 款级科目收了 12 项，漏了 30106 伙食补助费
- **现象**：区县教育局决算（伙食补助费 832.31 万元）明细合计比总额少一截
- **原因**：301 款级科目实际是 **13 项**：基本工资 / 津贴补贴 / 奖金 / **伙食补助费** /
  绩效工资 / 养老 / 年金 / 职工医保 / 公务员医疗补助 / 其他社保 / 住房公积金 / 医疗费 / 其他
- **修法**：`SUBITEMS` 补 `("伙食补助费","cash")`；同时注意 30111 有的地方写「公务员医疗补助**缴款**」

### 42. PDF 表格页里，「金额单位：万元」和「在职人数」全被丢掉
- **现象**：广东局决算 PDF 金额单位识别失败（按数量级猜），人数永远抽不到
- **原因**：`pdfplumber.extract_tables()` 只返回**表格内**单元格；
  单位标注、表格标题、人员情况段落都在表格**外**，且代码写了
  `if not rows: rows = text_lines` —— 只要有表格，整页文本就被整段丢弃
- **修法**：表格页**同时**保留一份整页文本行（`pageN-text`）；
  HTML 亦然（表标题常在 `<table>` 外层，需沿祖先回溯 1~3 层找）

### 43. 决算公开表根本不写人数 —— 「人均」卡在分母上
- **现象**：省局 PDF（2024/2025）与区教育局 HTML，正文表格都没有「在职 XX 人」
- **原因**：`部门决算公开表` 是**表格集**，人员情况属"部门基本情况"，多数单位不落数字；
  `data-sources.md §六` 原先假设「决算说明里有人员情况」，**这个假设不成立**
- **修法**：脚本抽不到人数**直接报错**并给出三个官方取数处（预算说明 / 编制年报 / 三定方案），
  另设 `--no-headcount` 只出分子与结构；**绝不用编制人数静默替代**（编制 ≥ 实有，人均会被压低 10~20%）

### 44. 单位决算「人均」不能用来估公务员收入 —— 混合事业编与教师
- **现象**：想按「单位决算工资福利支出 ÷ 该单位人数」给岗位定价，广州卫健委 82,186 万、
  教育局若按此算人均会被教师拉低，得出「当公务员不如当老师」的荒谬结论
- **原因**：部门决算覆盖**整个部门系统**，混了事业编、工勤、临聘。教师/医生与公务员是
  **不同工资体系**，不能混在一个分母里。且广州 18 个市级单位实测决算公开表**全部不披露人数**
- **修法**：单位对公务员收入的真实影响只有「政策规定的专项津贴」（政法+10%/乡镇+4%/执法+3%/纪检+3%），
  用 `salary_official.py` 的**统计年鉴基准 × 单位系数**替代单位决算人均；决算只用于展示单位规模差异

### 45. 「地区收缩指数 λ」的区间端点写反了（ratio<1 时 λ=0 不是下限）
- **现象**：官方基准版初版把「区间下限(λ=0)」「区间上限(λ=1)」固定标签，东莞(ratio=0.77)
  输出下限 15.8 万 > 上限 13.3 万，区间颠倒
- **原因**：λ=0 是「全省统一」、λ=1 是「完全跟随企业工资」。对 ratio>1 的城市（深圳）λ=0 是低值；
  对 ratio<1 的城市（东莞）λ=0 反而是高值 —— 端点不固定，取决于 ratio
- **修法**：下限 = 161,980×min(1,ratio)，上限 = 161,980×max(1,ratio)×(1+10%行政编溢价)，
  不再给 λ 端点贴「下限/上限」标签

### 46. 直接「市全行业平均 × 行业溢价系数」会把产业结构当工资差异
- **现象**：初版东莞算 12.4 万，比佛山还低，与「两地公务员收入相当」的常识相悖
- **原因**：东莞制造业工人多、全行业平均被拉低。机关工资由「全省统一的职务级别工资+规范津补贴」构成，
  地区差异被制度**压缩**，不像企业那样完全跟市场
- **修法**：引入收缩指数 λ=0.6，`市应发 = 全省公管行业平均 × (市/全省全行业)^0.6`，
  既承认财力差异又不吃进产业结构噪声；表中同时给 λ=0/λ=1 两个极端作区间

### 47. 决算表「职工医保缴费」异常小 —— 广州机关医保走财政统缴
- **现象**：广州 4 个市级单位决算里「职工基本医疗保险缴费」只有 3.25 万 / 5.92 万，
  而养老缴费是 577 万 / 4,911 万，医保比养老小 180 倍 → 用医保反推人数得出「2 人」的荒谬结果
- **原因**：广州市机关事业单位医保由财政统筹/公务员医疗补助单独列支，决算表里
  该项只记了一个零头。医保费率本应约为养老+年金(24%) 的 1/3
- **修法**：`estimate_headcount` 加守卫——医保额 < 养老额 1/10 时判为「数据不可用」跳过，
  只用养老+年金（24% 固定费率）与公积金（12%）两条线反推

### 48. 单位间薪资差异远超「考区平均」——按考区估会差 76%
- **现象**：广州市级机关（科技局/发改委/法院）决算反推人均到手含公积金 29~45 万，
  而统计年鉴口径「广州全市机关平均」只有 17.4 万 —— 差 76%
- **原因**：全市平均混了基层街道、乡镇、事业编；市级机关干部职级高、专项津贴多。
  这正是用户坚持「按单位算」的根本原因，考区平均严重失真
- **修法**：`salary_by_unit.py` 按「岗位所在单位」逐个抓决算；抓不到就写「未取得」，
  绝不拿考区档位冒充单位数据

### 49. 可报岗位绝大多数在县级单位，决算散落在几十个县政府门户
- **现象**：302 个可报岗位里仅 14 个是市级单位，其余 288 个在县/区/县级市
  （陆丰 19、兴宁 9、紫金 9、雷州 8、普宁 8…）
- **原因**：省考「乡镇机关」「县区局」岗位占绝对多数，县区单位决算公开在
  **各自**的县政府门户，栏目路径、分页、附件命名全都不一样
- **修法**：`unit_budget.SITES` 按「市/县」逐个配置栏目地址（已配广州、东莞、湛江、汕尾、
  郁南、高州）；`salary_by_unit.classify` 把单位分到站点，未配置的如实标注
  「未取得：需配 X 站点」。**这是持续工程，不是一次性能跑完的**

## 六、选岗方法论改造补坑（★ 2026-11，与薪酬双算法配套）

### 50. 区平均分 ≠ 岗位线，别用区级均值推单个岗位
- **现象**：用「远郊区 65–70 分」推南沙发改局，结果比真实线**低估 5–7 分**
- **原因**：区均值是全区岗位的混合分布（含大量乡镇、冷门岗）；热门局本级岗位的线
  显著高于区均值，属于**分布右尾**
- **修法**：热门岗要看**同类岗锚点**（同区同层级同性质的单位），不能用区均值线性外推；
  取不到锚点就明说无法给出该岗进面线，不要给一个看起来合理的数

### 51. 机构合并行可能是模板拼接，同一行数据不代表同质
- **现象**：某机构的汇总表里「番禺」被记成远郊，与官方口径不符
- **原因**：机构做表时用模板批量填充，区名与分档不匹配（模板拼接痕迹）
- **修法**：任何**机构整理的合并行**都要回到官方职位表核对区名与层级；
  对不上的整行作废，不做取中间值的折中

### 52. 限应届岗不可与不限应届岗直接对比分数
- **现象**：把限应届岗的进面线和不限应届岗放在一起排名，结论完全失真
- **原因**：限应届岗的报考池只有应届生（人数少 1–2 个数量级），分数线与不限岗**不可比**
- **修法**：分池比较——限应届 / 不限应届各算各的均值与分布；
  跨池只做量级描述，不做高低结论

### 53. 部门预算几乎都不披露在职人数
- **现象**：SKILL 原公式「工资福利支出 ÷ 在职人数」在实测 6 份预算里**6 份都缺分母**
- **修法**：改用 scripts/budget_salary.py 的**双路径互证**（工会经费 ÷ 2% 与
  工资福利支出 − 单位缴费），人数用「内设机构数 × 每科室 3~4 人 + 局领导」反推；
  反推区间必须在报告里显式给出，且标注为推算

### 54. 基本工资占工资福利 > 60% 是集中列支，不能做个人薪资参照
- **现象**：海珠区教育局（本级）2026 预算：工资福利 10,525.85 万，其中基本工资
  8,248.95 万（**78.4%**）、公积金仅 147.22 万（**1.4%**）
- **原因**：把**全区教师工资集中在教育局本级列支**，人均值会被教师基数稀释，
  与在教育局机关上班的人完全无关
- **修法**：`budget_salary.py` 自动拦截（阈值 60%），并附加独立信号
  「公积金占比 < 3% 为异常」（正常机关科室应在 7–12%）；
  触发即**拒绝输出个人薪酬结论**，不给仅供参考的折中值
### 55. 跨列合并的专业必须按空格分段匹配，否则误杀整批岗位（★ 2026-11-05 实跑发现）
- **现象**：广东省考省直三岗（`19900952741001` 退役厅 / `19900792741001` 省委金融办 /
  `19900662741002` 省市监局派出机构）与越秀仲裁院全部被判「专业不符」，
  而它们的本科专业列明明写着 `法学(B030101)`
- **原因**：广东把专业拆成「研究生 / 本科 / 大专」三列，`mapping.ts` 把三列合并后有值的一起
  以**空格**拼接 → 岗位专业变成 `法律（法学）(A030112) 法学(B030101)` 这样一整段；
  `majorHit` 只按 `、，；/` 分段，不认空格，于是要求「一个分段同时等于两个专业」
- **修法**：`split(/[,，、;；/／\s]+/)` 把空白也当分隔符。
  **这类缺陷只在真实表上暴露**——合成 fixture 是单列专业，跑不出问题
  （已补 `tests/test_gd_realworld.py` 用真实的三列结构断言）

### 56. 省考的「区」与「省直」写在招考单位里，不在考区列（★ 2026-11-05）
- **现象**：用真实广东职位表跑，南沙发改局显示成「广州 18–25 万」、省直三个岗也落到市档，
  区际 6.5–12 万的差距与省直 A 级预算档全部失效；同时「排除越秀」对越秀的岗位完全不生效
- **原因**：广东省考职位表的 `考区` 列只有 21 个地市名（`广州` `深圳`），
  区名（`广州市南沙区…`）与省直身份（`广东省退役军人事务厅`）都在 `招考单位` 列；
  而 `estimateSalary` 与排除区匹配原先都只喂 `job.region`
- **修法**：新增 `estimateSalaryForJob({unit, region})`——**先单独用单位名判定**，
  命中区级/省直档就用它，判不出来才退回考区或「单位 + 考区」拼接。
  不能直接拼：`isProvinceLevel` 见到「广州」里的「州」会判非省直，省直岗会被打回市档。
  排除区匹配改为扫 `单位 + 考区 + 薪酬展示名`


### 57. 跨省选岗第一步要先查「笔试是否同日」而非直接筛岗（★ 2026-11-05）
- **现象**：为浙江省考 2027 跑完全表筛选（3298 → 21 岗）后才发现，广东与浙江笔试
  **同为 2026-12-06**；广东下午场（14:00 行测 / 16:15 申论）与浙江全天场
  （9:00 行测 / 14:00 申论）完全重叠，物理上不可兼报，整个筛选结论的用途
  从「报哪个岗」变成「要不要换赛道」
- **原因**：选岗技能原先默认一次只处理一个省，漏斗里没有「考试日期冲突」这一层
- **修法**：**多省并行时，先把公告的时间三要素（报名窗口 / 笔试日 / 科目时段）
  拉成对照表放在筛选结果最前面**，再做岗位漏斗。已写入
  `references/zhejiang-2027-screening.md` 第一节
- **附带教训**：省份之间报名窗口不冲突 ≠ 可以都报；**决定权在笔试日**

### 58. 年龄卡口要按「岗位年龄列」逐条过滤，不能用 35 岁一刀切（★ 2026-11-05）
- **现象**：浙江省考里警察岗限 30 周岁、共青团岗限 28 周岁，本人 33 岁，
  若只按公告的总年龄上限（18–35）判断，会误留 100+ 个实际不可报的岗
- **修法**：漏斗中显式 `~年龄要求.str.contains("30周岁|28周岁")`。
  同理，省级机关法学岗为 0 的主因就是监狱警察限 30 岁 + 法检助理限应届
