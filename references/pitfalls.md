# 踩坑记录（累积中）

> 每条都是**实际踩过并修复**的，附现象与修法。新坑追加到末尾。

## 一、数据获取类

### 1. 国家公务员局下载页是 JS 渲染
- **现象**：`curl` 下载页只得到 2 KB 的空壳 `<ul id="download_ul">`
- **原因**：列表由 `gkdownloads.js` 异步填充
- **修法**：走接口 `http://dl.scs.gov.cn/api/res/{webRootId}/1110` → `resList`

### 2. webRootId 跨年度会变
- **现象**：2027 的 id 是 `8a81f6eca0221f1401a0242759fc0000`，硬编码后换年份就失效
- **修法**：从 `core-constant.js` 动态读 `neu.hb01Id`

### 3. 资源列表在公告当天下午才出现
- **现象**：10/13 上午 11:10 查 `resList` 为空；14:04 再查出现「招考简章.zip」
- **修法**：不要因为"列表为空"就认为没发布，下午再查

### 4. 税务系统官网普遍有 WAF
- **实测（2026-10-13 首测）**：总局 `www.chinatax.gov.cn` → 403；宁波 → 412；陕西 → 000
- **实测（2026-10-14 复测，同一沙箱）**：总局 `www.chinatax.gov.cn` → **200 可达**；
  广东 → 200；浙江 → 200；**陕西 → 412**（首页与文章页都拦，但见 #26）；宁波 → 412
- **结论**：WAF 状态**会随时间变化**，不要照抄历史结论；每次都重新测一遍
- **修法**：脚本报错时提示"在本机运行"；**不得**因此改用第三方镜像

### 5. 附件相对路径的基准是页面所在目录
- **现象**：页面 `.../2026-02/02/content_abc.shtml` 里 `href="abc/files/x.xls"`
- **错误拼法**：`.../content_abc.shtml/files/x.xls` → 404
- **正确**：`.../2026-02/02/abc/files/x.xls`（用 `urljoin(page_url, href)` 自动处理）

## 二、解析类

### 6. 面试名单表头含换行
- **现象**：列名实为 `进入面试\n最低分数`，直接按 `进入面试最低分数` 取会 KeyError
- **修法**：列名归一化（去 `\s` `（）` `：`）

### 7. 同一岗位多行，只有首行带分数
- **现象**：一个岗位 3 个进面考生占 3 行，只有第一行有分数
- **修法**：对「职位名称及代码」列**前向填充**（`ffill`）

### 8. 主名单与递补名单同代码重复
- **现象**：递补公告会再发一份名单，同职位代码重复出现且分数不同
- **修法**：同代码去重，**保留分数更高者**（主名单分数 ≥ 递补）

### 9. 职位代码需从"单位+职位"串里提取
- **现象**：多数税务局把代码并在名称里：`国家税务总局XX税务局一级行政执法员（二）（300110101002）`
- **修法**：正则 `(\d{12})` 提取，并剥离尾部括号

## 三、资格审查类（job-picker 引擎）

### 10. 国考职位代码**跨部门重复**
- **现象**：省级以下 18193 行，唯一「职位代码」仅 6339 个 → 按代码去重**丢掉 2/3 岗位**
- **实例**：`300110004001` 同时属于北京市通信管理局·业务处室 和 内蒙古自治区通信管理局·政策法规处
- **修法**：唯一键用「职位代码 + 用人司局」

### 11. 限应届的国考写法
- **现象**：规则只匹配「应届毕业生」连写，漏掉「**2027届**高校毕业生」
- **后果**：9008 个限应届岗位被误判为"符合"
- **修法**：覆盖 `XX届高校毕业生 / 应届高校毕业生 / 仅限XX届`

### 12. 专业匹配：太松与太紧都错
- **太松**：「大气物理学与大气环境」（属大气科学类）被 `includes("物理学")` 命中 → 5 个气象局岗位误入
- **太紧**：「大学本科：法学类（030101K）」带前缀未剥离 → 漏判央行阳江岗
- **修法**：按分隔符 `[,，、;；/／]` **切段** → 剥离括号内代码 → 剥离 `大学本科：` 类前缀 → **精确比对**段

### 13. 岗位代码与会话内的其他字段同名
- **现象**：zsh 环境下变量名 `path` 与内置 `$path`（绑定 PATH）冲突，把环境搞坏
- **修法**：脚本内不要用 `path` 作变量名

## 四、省考职位表（与国考差异大）

### 14. 表头不在第 1 行
- **现象**：广东 6 个 sheet 的表头分别在**第 2 行或第 3 行**，且各不相同
- **修法**：自动探测表头行（在前若干行里找"同时含职位与人数列"的行）

### 15. 专业拆成多列
- **现象**：广东拆为「研究生专业名称及代码」「本科专业名称及代码」「大专专业名称及代码」
- **修法**：`Mapping` 值类型扩展为**数组**，支持一字段合并多列

### 16. 广东专业列含括号代码
- **现象**：`哲学(A01),经济学(A02),法学(A0301)`
- **修法**：先剥离 `(...)` 再切段比对

### 17. 浙江「现有身份要求」= 「2025年应届毕业生」
- **现象**：`parseGrassrootsYears` 用 `/(\d+)/` 抓数字 → 抓到 **2025** → 判成"要求 2025 年基层经历" → 5 < 2025 → **1884 个岗位被误杀**
- **修法**：含「应届」直接返回 0；数字必须紧跟「年」单位；加负向边界（顺带修掉 `1988年` 被截成 `88年`）

### 18. 定向招录被静默放过
- **现象**：「优秀村干部 / 退役军人 / 服务基层项目人员」无法解析年限 → 判 pass → 普通考生报不了却显示"符合"
- **修法**：无法识别的身份文本降级为 `warn`

### 19. 体测门槛可能不在表格里
- **现象**：广东公安的体能测评要求写在**公告正文**，表格无此列 → 文本扫描抓不到
- **修法**：浙江有独立「是否体能测试」列 → 新增字段；广东侧改为识别单位名含公安/监狱/戒毒/边检

## 五、数据来源类（★ 最重要）

### 20. 进面分只在面试名单里，职位表没有
- **现象**：一度用"两个极端值外推四档区间"（如城区 130–140）
- **后果**：西安新城区实际 **116.9**，外推值 130–140 → **偏差 13–23 分**
- **修法**：**一律从面试名单取**，取不到就写"无法获取"

### 21. 第三方镜像虽然内容相同，也不能当作来源
- **现象**：官网被 WAF 拦时，机构 CDN（如 `u3.huatu.com`）能拿到官方附件原文
- **问题**：无法验证未被修改，且来源不可追溯
- **修法**：`_guard.py` 域名白名单**硬拦截**；官网不可达时如实报告，请用户在**本机**重试

### 22. 历史报录比没有一手来源
- **现象**：官方只在**报名期**实时公布报名人数，考后关闭
- **修法**：不提供历史报录比；用**进面分**作竞争度代理（一手、可查）

### 23. ★ 12 位职位代码**跨省不唯一**（与 #10 是两回事）
- **现象**：税务系统各省局**独立编号**。实测 `300110106001` 同时出现在**广东 / 浙江 / 陕西**的名单里，
  且单位完全不同（珠海万山海洋开发试验区税务局 / 温州市税务局第二稽查局 / 西安市灞桥区税务局）
- **数量**：本次三省 1182 个岗位中有 **134 个代码跨省重号**（约 11%）
- **后果**：按「职位代码」单键去重，会把别省的岗位**静默吃掉**——总数变少但看不出任何异常
  （实测：1040 vs 正确 1182，少了 142 个）
- **修法**：唯一键必须用 **(省份, 职位代码)**；`lookup` 按代码聚合、把命中的所有省份都列出来并给警告
- **同理**：**跨年度也不复用**——陕西 2021 年 `300110001001` 是「西安市新城区税务局」，
  2026 年是「陕西省税务局稽查局」。所以拿旧代码直接查今年岗位是无效的

### 24. 前向填充必须**先于**按代码筛行，否则「进面人数」恒为 1
- **现象**：解析出的每个岗位 `进面人数` 都是 1，但原始表明明有 3~9 行
- **原因**：代码先执行了「只保留含 12 位职位代码的行」——而**续行的代码列是空的**，
  整行被删掉，后面的 `ffill` 就没有东西可填了
- **修法**：顺序改成 ① `ffill` ② 提取代码 ③ 判「考生行」（姓名或准考证号非空）④ 分组计数
- **验证**：`进面人数` 合计应等于「原始表总行数 − 表头行数」（本次 4020 / 2117 / 2150 完全对上）

### 25. CMS 下载链接里没有文件名，且 `ATTACH_RE` 不能拿裸 URL 去匹配
- **现象 A**：浙江/陕西的附件链接形如
  `/module/download/downfile.jsp?classid=0&filename=<uuid>.xls` —— **URL 里没有可读文件名**
- **现象 B**：广东的链接路径就是 `<uuid>.xls`，真名只写在 `<a>` 的 **文字或 `title` 属性**里
- **后果**：只按 URL basename 命名，会让同一页的多个附件重名互相覆盖
  （浙江 6 个附件全存成 `downfile.jsp.xls`）；广东则全是 UUID 名，`来源文件` 字段无法追溯
- **坑中坑**：`ATTACH_RE = 'href="([^"]+\.(?:xls|…))"'` 匹配的是**整个 `href="…"` 片段**，
  拿已经拆出来的**裸 URL** 去 `ATTACH_RE.search()` **恒为 None** → 所有附件都掉进无文件名的兜底分支
- **修法**：① 正则同时捕获 `<a>` 标签与内部文字（文字为空再取 `title`）；
  ② 附件判定改用独立函数（看路径后缀，或 `filename/showname` 查询参数）；
  ③ 重名自动加 `(n)` 后缀，不静默覆盖

### 26. 陕西站 412 是「瑞数」动态 JS 防护，但**附件下载接口不受保护**
- **现象**：`https://shaanxi.chinatax.gov.cn/` 与 `/art/…html` 全返回 **412**，
  响应体是混淆 JS + `$_ts` 变量 + 设置 cookie 后重载，属瑞数动态防护，requests 无法直接过
- **但是**：`/module/download/downfile.jsp?classid=0&filename=<uuid>.xls` → **200，348 KB 正常**
  （WAF 只护 HTML 页面，不护文件下载 servlet）
- **修法**：**分工取数** —— 用浏览器或 **WebFetch 打开公告页拿附件 UUID**（WebFetch 能过 WAF），
  再用 `requests` 直连 `downfile.jsp` 下载；`fetch` 已支持传附件直链
- **同类**：`www.scs.gov.cn` 也是 JS 挑战页（`__tst_status` cookie），并非真不可达

### 27. 县/县级市税务局的名称里没有省级关键词 → 省份识别失败
- **现象**：`国家税务总局建德市税务局`、`国家税务总局博罗县税务局` —— 既没有「浙江/广东」，
  `国家税务总局([\u4e00-\u9fa5]{2,6}?)(?:省|市|自治区)` 也只能抓到「建德」，落不进映射表
- **后果**：`省份` 字段出现 `建德 / 乐清 / 龙港 / 玉环 / 兰溪 / 龙泉 / 江山 / 永康` 等县级市名
- **修法**：① 县级市不认识的**不要提前 return**，继续走关键词兜底；
  ② 兜底仍失败 → 用**该文件的多数省份**修正（一份面试名单只覆盖一个省，这个假设很稳）
- **附带**：把常见的县级市补进 `CITY_TO_PROVINCE`（浙江：建德/乐清/龙港/玉环/兰溪/龙泉/江山/永康/安吉/嘉善…）

### 28. 旧年度的考录专题站已下线，历史进面分只能回省局取
- **现象**：`http://bm.scs.gov.cn/kl2026`、`/kl2025` → **404**（nginx）
  现存的只有当年度 `kl2027`，而其「相关下载」只有招考简章 + 报名表格
- **含义**：`sources.py` 里那句「国家公务员局一次拿到全量面试名单」**只对当年有效**，
  一旦跨年度，那年的专题页会消失
- **修法**：取**历史**进面分一律走**各招录机关（省局）官网**的面试公告栏目；
  同时别指望"一个文件覆盖全国"
- **补充实测（2026-10-14）**：国家局下载接口 `/api/res/{root}/{cid}` 的分类 id 换成
  `1100~1130` 任意值都返回**同一份当年资源列表**（参数形同虚设），
  即老年度文件在下载服务器上**也拿不到**。

### 29. ★ 瑞数 WAF 只护 HTML 页面，`/module/*` 接口一律放行
- **这条是本项目突破 WAF 的通用打法**，两个可用通道：
  1. **文件下载**：`/module/download/downfile.jsp?classid=0&filename=<uuid>` → 200 正常返回文件
  2. **列表检索**：`/module/xxgk/search.jsp` → 200，能拿到栏目全量文章列表
- 被拦的只有：`/`、`/index.html`、`/col/…`、`/art/…`、`/robots.txt`、`/sitemap.txt`、`/jsearchfront/…` → 全部 412
- **实操**：不要去执行 JS 挑战、不要装无头浏览器。**页面用 WebFetch 读，数据用 `/module/*` 直连**。
  （本次就是靠这个把"陕西站完全不可达"变成"三省全部取到"。）

### 30. 陕西站（苏迪 CMS）信息公开列表的正确调法 ★ 已固化为命令
- **现象**：`POST /module/xxgk/search.jsp` 若参数不全，返回 `请传入正确参数！`（57 字节）
- **可用最小参数集**（缺一不可，**多了也不行**）：
  ```
  POST /module/xxgk/search.jsp
  infotypeId=A07              # 人事管理
  jdid=1
  area=11610000160006543      # 该站的信息公开区域码
  columnid=32162              # 公务员招录栏目
  divid=list
  ```
  另外必须带 `X-Requested-With: XMLHttpRequest` 与 `Referer: …/col/col32162/index.html`
- **坑 1**：多加的参数（`page` / `currentpage` / `pagenum` / `startrecord`…）会让它退回「请传入正确参数」，
  或**被直接忽略**——实测 8 种分页参数全部无效，接口**固定返回最新 20 条**（一般覆盖近两年，够定位年度公告）
- **坑 2**：浙江站是**同一套 CMS**，只是参数不同
  （`infotypeId=Z2402 & jdid=15 & area=11330000002484088Y & columnid=24800`）；
  **广东站不是**这套 CMS，没有该接口
- **✅ 已固化为命令**，不用再手工拼参数：
  ```bash
  python3 scripts/interview_scores.py discover --site list
  python3 scripts/interview_scores.py discover --site 陕西 --year 2025 --kw 面试
  ```
  预设表在 `SITES`（`scripts/interview_scores.py`）；新增省份只需补 `columnid/infotypeId/jdid/area` 四项
- **返回**：一个 HTML 表格，含 20 条文章（标题 + 责任处室 + 日期 + 链接）

### 31. 该 CMS 的锚点用**单引号**，双引号正则会漏掉全部链接
- **现象**：`href='https://…/art/2025/2/5/art_32162_637838.html?xxgkhide=1'`
  → 只写 `href="…"` 的正则命中 **0 条**，但用「找 `art_xxxxx_xxxxxx.html` 子串」的宽正则能命中 20 条
- **后果**：会误判为"列表页没有链接 / 接口没返回数据"
- **修法**：解析政府站 HTML 时，`href` 的引号**两种都要兼容**（`href=["\']([^"\']+)["\']`）

### 32. `_unique_path` 只查内存不查磁盘 → 分批 fetch 会静默覆盖附件
- **现象**：先抓浙江、再抓广东的 2025 递补公告，两个附件都叫 `递补面试人员名单.xls`
  → 第二次把第一次的文件**覆盖**了，且文件名相同、大小接近，肉眼几乎发现不了
- **原因**：重名集合 `used` 是 `fetch()` 内的局部变量，每次进程调用都重置，**不查磁盘**
- **修法**：去重判断同时看 `used` 和 `os.path.exists(outdir/name)`
- **更稳的做法**：跨省抓取时，别依赖自动命名，**抓完立刻重命名为 `省份_年份_名单类型.xls`**，
  并在解析前用「单位名里出现的省份关键词」反查文件归属（本次就这样救回了被覆盖的浙江递补）

### 33. WebFetch 对同一站点的个别页面会偶发「No readable content found」
- **现象**：同一站点、同样结构的两页，一个能读、一个连续 3 次报
  `No readable content found on the page`
- **修法**：**加一个无害的查询参数破缓存**再试，例如
  `…art_32162_637838.html?xxgkhide=1&v=2` —— 加上后立刻读到了完整正文与附件直链
- **不要**因此就判定"页面为空"或"站点不可达"

### 34. 不要为了过 WAF 去装无头浏览器 —— 本次是死路，且有环境坑
- **过程**：为攻破陕西站，装了 `agent-browser`（`npm i -g agent-browser`）想用真浏览器过瑞数挑战
- **结果**：**完全没用上**。真正解决问题的是 #29 的 `/module/*` 接口
- **若将来确实要用，两个坑先记下**：
  1. `npm i -g agent-browser` 生成的 shim 在 **Git Bash 下路径拼错**：
     `Cannot find module 'c:\c\Users\…'`（`/c/…` 被当成相对路径又加了盘符）→
     绕过办法：`node "$(npm root -g)/agent-browser/bin/agent-browser.js" <cmd>`
  2. 本机**没有 Chrome**，会自动去下载（~数百 MB）→ 改用系统自带的
     Edge：`--executable-path "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"`
     （注意：`--executable-path` 在守护进程已启动时会被忽略，必须先 `close`）
- **结论**：**先试 `/module/*` 接口通不通**；通了就完全不需要浏览器
