## 二、职位表（入口最稳的一手源）

**官方入口**：<http://bm.scs.gov.cn/kl2027> → 「相关下载」

**技术细节**（页面是 JS 渲染，直接抓 HTML 拿不到列表）：

```
① 资源列表接口
   http://dl.scs.gov.cn/api/res/{webRootId}/1110
   → {"resList":[{"resResourceId":"...","resourceName":"...zip","resourceComment":"..."}],
       "cacheInfo":{"achieveTime":"..."}}

② 文件下载
   http://dl.scs.gov.cn/download/{resResourceId}
```

**webRootId 获取**：访问下载页 → 载入 `core-constant.js` → 字段 `neu.hb01Id`
（2027 年度实测值 `8a81f6eca0221f1401a0242759fc0000`；跨年度会变，须动态读取）

**实测证据**（2026-10-13）：
- `resList` 在 11:10 为空 → 14:04 出现「中央机关及其直属机构2027年度考试录用公务员招考简章.zip」
- 下载成功 9.65 MB → 解压得 `.xls`（4 sheet / 19403 岗）

> **用途**：职位表是绝大多数分析的底座（招录人数、专业、学历、政治面貌、基层年限、备注）。

## 三、面试名单（进面分的**唯一**一手来源）★

**为什么关键**：职位表里**没有进面分**。进面分只在面试名单里，由各招录机关在**次年 1–2 月**单独发布。

**官方入口**：各招录机关官网 → 「公务员招录」栏目 → 面试公告 → 附件

文件内表格结构（实测两种写法，脚本已自适应）：

| 写法 | 列 |
|---|---|
| A（多数税务局） | `职位名称及代码` \| `进入面试最低分数` \| 姓名 \| 准考证号 \| 面试时间 \| 备注 |
| B（部委） | `用人司局` \| `招考职位` \| `职位代码` \| `最低面试分数` \| 准考证号 \| 姓名 \| 面试时间 |

> ⚠️ 同一岗位**每个进面考生占一行**，只有首行带分数 → 解析时必须**前向填充**。

**沙箱可达性实测（2026-10-13）**：

| 机关 | 域名 | 结果 |
|---|---|---|
| 国家税务总局广东省税务局 | `guangdong.chinatax.gov.cn` | ✅ **200，附件可下载** |
| 国家税务总局陕西省税务局 | `shaanxi.chinatax.gov.cn` | ❌ HTTP 000（被网络策略拦） |
| 国家税务总局宁波市税务局 | `ningbo.chinatax.gov.cn` | ❌ HTTP 412（WAF） |
| 国家税务总局（总局） | `www.chinatax.gov.cn` | ❌ HTTP 403（WAF） |
| 国家发展改革委 | `ndrc.gov.cn` | ✅ 200（可下载名单） |

> **⚠️ 重要说明**：上述失败是**本沙箱的网络策略**所致，**不代表你的电脑访问不了**。
> 脚本按「只接受官方域名」设计：**在你本机运行时，被拦的省份通常能正常抓取**。
> 沙箱内失败时，脚本会明确报错并给出**手动下载指引**，**不会**改用第三方数据源。

## 四、报名人数 / 报录比（唯一没有历史一手数据的指标）

| 情形 | 能否取得 | 说明 |
|---|---|---|
| **报名期**（如 10/15–10/24） | ✅ 可以 | 官方报名系统逐日公布各岗位报名/过审人数 |
| **报名期之后** | ⛔ **不存在一手来源** | 系统关闭，官方不提供历史存档 |

**因此**：
- **历史报录比（如"2026 税务 94.5:1"）没有官方出处** → **本框架不提供**
- 想用报录比，只能在**报名期自己盯**（见 SKILL.md §五）
- 考完之后要评估竞争度 → **用「进面分」做代理**（一手、可查）

## 五、合格分数线

**来源**：国家公务员局公告正文（如「2025 年度考试录用公务员笔试合格分数线」）

例：行政执法类职位 → 总分 95 分 / 行测 50 分。

> 这是**官方**数据（唯一有官方口径的分数标准），但只是"入围门槛"，≠ 进面线。

## 六、部门预算 / 决算（薪酬推算的输入）

**来源**：各单位官网「预算公开 / 决算公开」栏目 → 部门预算表 / 部门决算表

**需要的字段**：
- `工资福利支出`（决算表中「基本支出」或「财政拨款支出」明细）
- **在职人数**（决算说明中的"人员情况"或"编制及实有人数"）

**推算公式**：

```
人均工资福利支出（年） = 工资福利支出 ÷ 在职人数
```

⚠️ 必须标注 `（推算）`，并附：分子来源、分母来源、年份。

**待验证**：`www.chinatax.gov.cn` 在沙箱返回 403，需改用**具体省局 / 县级局**网站的预算公开页，
或由用户在浏览器手动下载。**不要用新闻稿或论坛转述的"某地公务员年薪"**。

## 七、房价

**来源**：国家统计局《中国统计年鉴》→「各地区商品房平均销售价格」/「分城市数据」

- `stats.gov.cn` 沙箱可达 ✅
- 若需区县级，用**当地住建局**的网签均价公告（官方）

**禁用**：中介挂牌均价（贝壳/安居客）、商业数据站的"估算均价"——除非明确标注为非官方参考。

## 八、⛔ 禁用来源清单

| 类别 | 特征 | 举例 |
|---|---|---|
| 培训机构统计 | 域名含 `huatu` `offcn` `fenbi` `jinbiaochi` `gwy.com` `eduu` | 中公职位库、华图分数线库 |

> **例外为零**。需要某个数字 → 回官方取。取不到 → 写"无法获取"。

## 九、⚠️ 需要作废的既往结论（本框架启用前产生的）
