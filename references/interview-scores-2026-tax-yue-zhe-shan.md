# 2026 年度国考 · 税务局进面分（广东 / 浙江 / 陕西）

> **数据年份**：**2026 年度**（笔试 2025-11、面试 2026-03）。这是当前可取得的最新一个完整招录周期的官方进面分。
> **抓取时间**：2026-10-14（GMT+8）
> **覆盖**：国家税务总局 **广东省 / 浙江省 / 陕西省**税务局及其下属市、县（区）局
> **岗位数**：1182（广东 557 / 浙江 388 / 陕西 237）
> **数据文件**：[`interview-scores-2026-tax-yue-zhe-shan.csv`](./interview-scores-2026-tax-yue-zhe-shan.csv)

---

## 一、口径（先说清楚，避免误用）

| 字段 | 含义 |
|---|---|
| `省份` | 招录机关所属省（由单位名识别；一份名单只覆盖一个省，县局名识别不出时按该文件多数省份归位） |
| `职位代码` | 12 位国考职位代码。**⚠️ 跨省不唯一**——税务系统各省局独立编号，实测 134 个代码在粤/浙/陕之间重号，查代码时必须带上省份 |
| `单位及职位` | 用人司局 + 职位名称（已去掉末尾的 12 位代码） |
| `进面最低分` | **官方口径的进面线** = 该岗位进入面试人员的笔试最低分（行测+申论原始分相加，满分 200） |
| `进面人数` | 该岗位出现在**主名单**中的人数（官方 1:3 为主，因此 ≈ 3 × 招录人数） |
| `名单类型` | `主名单` = 面试公告附件1；`递补名单` = 递补公告附件 |
| `来源文件` | 对应 `references/raw/2026-tax/` 下的原始附件，可回溯 |

**分数性质**：两科原始分相加（满分 200），**不是**折算后的百分制，也**不是**合格分数线。

## 五、局限（必须同时告诉使用者）

1. **不是今年的线**：这是 2026 年度数据。2027 年度的进面分要到 2027 年 1–2 月官方才发布，**现在不存在**。
   用它做 2027 选岗参考时，只能当"同单位/同地区的历史水位"，**不能当预测值**。
2. **跨年不可直接比**：题目难度与阅卷尺度逐年变化，不同年份的绝对分不可直接相减。
3. **不代表竞争比**：官方历史报录比**不存在**（只在报名期实时公布），本表不含报名人数。
4. **递补已归并**：同一岗位若同时出现在主名单与递补名单，取**主名单**的那条（其分数才是官方进面线）；
   递补者本人在递补名单里的分数更低，不作为进面线。
5. **仅三省**：未覆盖其他省局，也未覆盖国考其他系统（海关、铁路公安、统计局等）。

## 六、复现方式

```bash
# ① 抓附件（公告页 / 直链均可）
python3 scripts/interview_scores.py fetch \
  --url "https://guangdong.chinatax.gov.cn/gdsw/ryzl/2026-02/02/content_60ef11015e004021a85cfe4179a1c14a.shtml" \
  --url "https://guangdong.chinatax.gov.cn/gdsw/ryzl/2026-02/28/content_8f6ca48f28584dca8460a0f5f12c4df7.shtml" \
  --url "https://zhejiang.chinatax.gov.cn/art/2026/2/2/art_24800_648916.html" \
  --url "https://zhejiang.chinatax.gov.cn/art/2026/2/28/art_24800_649868.html" \
  --url "<陕西直链见 §二，页面被 WAF 拦但附件接口可直连>" --out ./raw

# ② 解析
python3 scripts/interview_scores.py parse --dir ./raw --out scores.csv
```

> 陕西站 HTML 页面返回 **412（瑞数动态 JS 防护）**，但 `module/download/downfile.jsp` 下载接口**不受 WAF 保护**，可直连。
> 附件 UUID 用浏览器或 WebFetch 打开公告页取。
